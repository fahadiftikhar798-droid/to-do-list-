📖 About The Project
This is Project 1 for the DecodeLabs Internship Program. It's a simple Command Line Interface (CLI) To-Do List application built to demonstrate core Python fundamentals and Clean Code principles.

The goal was to build a working app that follows the IPO (Input - Process - Output) model and Separation of Concerns.

⚙️ Features
*   **Add Task:** Add new tasks to your list.
*   **View Tasks:** View all tasks with index numbers.
*   **Simple CLI:** Easy to use menu loop with 1, 2, 3 options.

💻 Core Concepts Used (As per requirements)
*   `my_tasks = []` - **Storage:** Using a Python List to store tasks
*   `append()` - **Process:** For adding new tasks (Data Logic)
*   `enumerate()` - **Output:** For displaying tasks with index (User Interface)
*   Functions `add_task()` & `view_tasks()` - **Decoupling / Modularity**
*   `if __name__ == "__main__":` - Professional execution pattern

🚀 How to Run
1.  Clone the repo
2.  Run `python todo.py`
3.  Choose:
    - `1` to Add Task
    - `2` to View Tasks (`0 - to do list`)
    - `3` to Exit
